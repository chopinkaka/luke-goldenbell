# 누가복음 골든벨

누가복음 골든벨 문제 335개를 카드로 넘기며 풀고, 누가복음 24장을 통독하는 개인 연습용 웹앱입니다.
휴대폰 홈 화면에 설치하면 인터넷 없이도 열립니다.

- 퀴즈: 옆으로 밀어 넘기기, 카드를 탭하면 정답, 장·유형별 범위와 섞기, ★ 다시 볼 문제
- 성경읽기: 장별 통독과 읽음 체크, 퀴즈에 나온 절 표시
- 퀴즈 카드의 근거구절(예: 눅 1:80)을 누르면 그 절 본문이 바로 보입니다.
- 개역개정 본문은 저작권 때문에 들어 있지 않습니다. 앱의 '개역개정 가져오기'로 직접 붙여넣은 본문은 그 기기에만 저장됩니다.
